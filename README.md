# 考试刷题系统

一个简单的浏览器端考试练习系统 MVP，支持题库管理、Excel 导入导出、随机刷题、错题本和练习测验。

## 功能

- 简单登录 / 退出登录
- 题库新增、编辑、删除、查询
- 题库 Excel 模板下载、导入、导出
- 支持单选、多选、判断题
- 随机刷题，提交后立即判断对错并展示解析
- 错题本自动记录错题，连续答对 2 次后自动删除
- 练习测验支持指定题目数量，按顺序或随机抽题

## 运行方式

本项目为静态页面，无需构建。

```bash
python3 -m http.server 8000
```

然后访问：

```text
http://localhost:8000
```

也可以直接用浏览器打开 `index.html`。

## 演示账号

```text
普通用户：student / 123456
管理员：admin / admin123
```

## Excel 字段

导入 Excel 的第一行字段建议使用：

```text
题型、题干、选项A、选项B、选项C、选项D、答案、解析
```

题型可填写：

- 单选
- 多选
- 判断

答案格式：

- 单选：`A`
- 多选：`A,B,C`
- 判断：`正确` 或 `错误`

## 数据存储

当前版本使用浏览器 `localStorage` 保存用户、题库、答题记录、错题本和测验记录。
